# Verilog Logic Gates Project

This repository contains basic IEEE 1364-compliant Verilog HDL implementations for all fundamental logic gates. Each folder includes individual logic gate modules designed using continuous assignment constructs.

## 📁 Repository Structure

```text
Logic_gates/
├── and_gate/     # 2-input AND gate implementation
├── exnor_gate/   # 2-input EX-NOR (XNOR) gate implementation
├── exor_gate/    # 2-input EX-OR (XOR) gate implementation
├── nand_gate/    # 2-input NAND gate implementation
├── nor_gate/     # 2-input NOR gate implementation
├── not_gate/     # 1-input NOT gate (Inverter) implementation
└── or_gate/      # 2-input OR gate implementation
